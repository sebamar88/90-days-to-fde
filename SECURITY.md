# Security policy

## Reporting a vulnerability

Do not report vulnerabilities or exposed credentials in a public issue. Use GitHub's private vulnerability reporting feature if enabled for this repository. If it is unavailable, contact the maintainers through the private contact route shown on the repository profile and request a secure channel. Include affected files, impact, and safe reproduction details; do not include real customer data.

## Scope

This repository is primarily educational content and small validation scripts. Security reports about unsafe guidance, vulnerable examples, scripts, or accidentally committed secrets are welcome. We will acknowledge reports as soon as practical and coordinate disclosure before publishing details.

If a secret is committed, revoke/rotate it immediately; deleting it from the latest revision does not invalidate an exposed credential.
